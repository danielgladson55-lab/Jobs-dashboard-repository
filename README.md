# Daniel's Job Intelligence Dashboard

A responsive job-discovery and prioritization dashboard for:

- Technology Risk
- IT Audit
- IT Internal Audit
- Cybersecurity GRC
- Risk Assurance
- IT General Controls
- IT Application Controls
- Third-Party Risk
- Cloud Security

## Dashboard Features

- LinkedIn Jobs shortcut
- Naukri Jobs shortcut
- Indeed Jobs shortcut
- GitHub Job Tracker shortcut
- Job title, company and skill search
- Chennai opportunity lane
- Bengaluru opportunity lane
- India-remote opportunity lane
- Global-remote opportunity lane
- Onsite, hybrid and remote filters
- Profile-based job match scores
- Recommended resume versions
- Official job application links
